# 113. 心臟病風險預測

## 項目概述

這是一個基於患者臨床數據預測心臟病風險的分類項目。利用機器學習方法分析患者的健康指標，早期識別心臟病高風險人群。

**Kaggle 數據集**: [Heart Disease Health Indicators](https://www.kaggle.com/datasets/alexteboul/heart-disease-health-indicators-dataset)

**難度**: ⭐⭐ 中級

## 目標

預測患者是否有心臟病風險（二元分類問題）

## 數據集描述

### 特徵說明

| 特徵 | 描述 | 類型 |
|------|------|------|
| age | 年齡 | 數值 |
| sex | 性別 (0=女性, 1=男性) | 二元 |
| cp | 胸痛類型 (0-3) | 分類 |
| trestbps | 靜息血壓 (mm Hg) | 數值 |
| chol | 血清膽固醇 (mg/dl) | 數值 |
| fbs | 空腹血糖 > 120 mg/dl (0=否, 1=是) | 二元 |
| restecg | 靜息心電圖結果 (0-2) | 分類 |
| thalach | 最大心率 | 數值 |
| exang | 運動誘發心絞痛 (0=否, 1=是) | 二元 |
| oldpeak | ST段壓低 | 數值 |
| slope | 運動ST段斜率 | 分類 |
| ca | 主要血管數量 (0-3) | 數值 |
| thal | 地中海貧血類型 | 分類 |
| target | 心臟病 (0=無, 1=有) | 目標變量 |

### 數據集大小
- Cleveland Heart Disease: 303 筆
- 完整合併數據集: ~900 筆

## 關鍵洞察

1. **胸痛類型**: 非典型心絞痛與心臟病風險較高
2. **年齡與性別**: 老年男性風險顯著升高
3. **運動測試**: 運動誘發ST段壓低是重要指標
4. **最大心率**: 較低的最大心率與心臟病相關
5. **血管數量**: 鈣化血管數量與風險正相關

## 技術方法

### 數據預處理
- 缺失值處理
- 異常值檢測與處理
- 特徵標準化
- 類別變量編碼

### 特徵工程
- 年齡分組
- 心血管風險評分
- 血壓分類
- 膽固醇風險等級

### 模型
- Logistic Regression
- Random Forest
- Support Vector Machine
- XGBoost
- 神經網絡

### 評估指標
- 準確率
- 召回率（敏感度）
- 特異度
- F1 分數
- ROC-AUC
