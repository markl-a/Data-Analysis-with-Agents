# 04. 客戶流失預測

## 📋 概述
預測電信客戶流失，幫助企業保留客戶。

**數據集**: [Telco Customer Churn](https://www.kaggle.com/blastchar/telco-customer-churn)
**難度**: ⭐⭐ 初級

## 🎯 目標
預測客戶是否會流失

## 📊 關鍵特徵
- tenure: 客戶在網月數
- MonthlyCharges: 月費用
- Contract: 合約類型
- InternetService: 網路服務類型

## 🛠️ 方法
- Random Forest Classifier
- 特徵編碼
- AUC-ROC評估

## 📈 業務價值
- 識別高風險客戶
- 制定保留策略
- 降低流失率
