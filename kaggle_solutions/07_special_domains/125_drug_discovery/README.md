# 125. 藥物發現 - 分子活性預測

## 項目概述

這是一個計算藥物發現項目，使用分子描述符和機器學習預測化合物的生物活性，加速藥物研發過程。

**Kaggle 數據集**: [Molecular Activity Prediction](https://www.kaggle.com/c/lish-moa)

**難度**: ⭐⭐⭐⭐ 專家級

## 目標

預測化合物對特定靶點的生物活性（多標籤分類）

## 數據集描述

### 特徵類型

| 特徵類型 | 描述 |
|----------|------|
| g- 特徵 | 基因表達數據 |
| c- 特徵 | 細胞活力數據 |
| cp_type | 處理類型 |
| cp_dose | 劑量水平 |
| cp_time | 處理時間 |

### 靶點類別

| 類別 | 描述 |
|------|------|
| MoA | 作用機制 (Mechanism of Action) |
| 多標籤 | 一個化合物可能有多個 MoA |

## 關鍵洞察

1. **高維數據**: 數百個基因表達特徵
2. **多標籤**: 一個化合物可能影響多個靶點
3. **類別不平衡**: 大多數靶點為負樣本
4. **特徵相關性**: 基因表達特徵間存在相關性

## 技術方法

### 特徵工程
- PCA 降維
- 特徵選擇
- 標準化/正規化
- 基因表達聚類

### 模型
- TabNet
- Neural Network (多層)
- LightGBM
- Stacking Ensemble

### 評估指標
- Log Loss
- AUC-ROC (per target)
- Macro F1

## 使用方法

```bash
python solution.py
```
