# Financial Risk Assessment System

## Overview
Comprehensive credit risk assessment system using machine learning to evaluate loan applications, calculate default probabilities, and implement risk-adjusted pricing.

## Problem Statement
Assess credit risk for loan applications to:
- Predict probability of default (PD)
- Calculate expected loss (EL = PD × LGD × EAD)
- Implement risk-adjusted pricing
- Optimize portfolio risk
- Ensure regulatory compliance

## Key Features
- Multi-model ensemble for PD prediction
- Expected loss calculation
- Risk-adjusted interest rate suggestions
- Portfolio-level risk metrics
- Basel II/III compliance framework

## Methodology
- Logistic Regression, Random Forest, Gradient Boosting
- ROC AUC optimization
- Cost-sensitive learning
- Feature engineering from credit bureaus

## Key Results
- ROC AUC: 0.85-0.92
- Expected loss rate: 2-4%
- Risk-based pricing optimization
- Portfolio risk quantification
