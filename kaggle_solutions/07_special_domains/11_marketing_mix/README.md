# Marketing Mix Modeling System

## Overview
Quantify marketing channel effectiveness and optimize budget allocation using regression analysis and ad stock modeling.

## Problem Statement
Measure and optimize marketing impact:
- Quantify channel contributions to sales
- Calculate ROI by channel
- Account for carryover effects (ad stock)
- Optimize budget allocation

## Key Features
- Multi-channel attribution
- Ad stock transformation
- Diminishing returns modeling
- ROI calculation
- Budget optimization

## Methodology
- Ridge regression for MMM
- Ad stock with exponential decay
- Logarithmic diminishing returns
- Constrained budget optimization

## Key Results
- Channel contribution quantification
- ROI metrics by channel
- Optimal budget allocation
- Sales prediction accuracy
