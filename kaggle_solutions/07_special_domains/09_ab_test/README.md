# A/B Test Analysis System

## Overview
Comprehensive A/B testing framework with frequentist and Bayesian analysis, segmentation, and statistical rigor.

## Problem Statement
Design and analyze A/B tests to:
- Determine statistical significance of changes
- Calculate required sample sizes
- Analyze segment performance
- Make data-driven decisions

## Key Features
- Sample size and power calculations
- Frequentist hypothesis testing
- Bayesian A/B testing
- Segment analysis
- Confidence intervals

## Methodology
- Two-proportion z-tests
- Bayesian posterior distributions
- Multiple comparison corrections
- Practical vs statistical significance

## Key Results
- Statistical significance at α=0.05
- Bayesian probability estimates
- Segment-specific insights
- Conversion and revenue lift
