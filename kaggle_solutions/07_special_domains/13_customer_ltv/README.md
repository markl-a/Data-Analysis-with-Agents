# Customer Lifetime Value Prediction

## Overview
Predict customer lifetime value to optimize acquisition costs and retention strategies using machine learning.

## Problem Statement
- Predict future customer value
- Segment customers by LTV
- Optimize CAC:LTV ratio
- Target high-value customers

## Key Features
- Historical and predictive LTV calculation
- Customer segmentation (VIP, High, Medium, Low)
- Behavioral feature engineering
- Channel attribution

## Methodology
- Random Forest and Gradient Boosting
- Feature engineering from behavioral data
- Quartile-based segmentation
- ROI optimization
