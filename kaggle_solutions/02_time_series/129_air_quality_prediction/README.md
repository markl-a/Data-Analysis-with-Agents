# 129. 空氣質量預測

## 項目概述

這是一個環境科學時間序列預測項目，利用歷史污染物數據和氣象因素預測空氣質量指數（AQI），支持環境監測和公共健康決策。

**Kaggle 數據集**: [Air Quality Dataset](https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india)

**難度**: ⭐⭐⭐ 進階

## 目標

預測未來空氣質量指數（AQI）或 PM2.5 濃度（時間序列回歸問題）

## 數據集描述

### 特徵說明

| 特徵 | 描述 | 類型 |
|------|------|------|
| date | 日期時間 | 日期 |
| PM2.5 | 細顆粒物濃度 | 數值 |
| PM10 | 可吸入顆粒物濃度 | 數值 |
| NO2 | 二氧化氮濃度 | 數值 |
| SO2 | 二氧化硫濃度 | 數值 |
| CO | 一氧化碳濃度 | 數值 |
| O3 | 臭氧濃度 | 數值 |
| temperature | 溫度 | 數值 |
| humidity | 濕度 | 數值 |
| wind_speed | 風速 | 數值 |
| AQI | 空氣質量指數 | 目標變量 |

## 關鍵洞察

1. **季節性**: 冬季污染通常更嚴重
2. **氣象影響**: 風速與污染物濃度負相關
3. **日變化**: 交通高峰期污染較高
4. **污染物關聯**: PM2.5、PM10、NO2 高度相關
