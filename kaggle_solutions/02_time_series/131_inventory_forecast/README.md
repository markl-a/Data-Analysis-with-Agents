# 131. 供應鏈庫存預測

## 項目概述

這是一個供應鏈管理項目，通過預測產品需求量來優化庫存水平，減少庫存成本和缺貨風險。

**Kaggle 數據集**: [Store Item Demand Forecasting](https://www.kaggle.com/c/demand-forecasting-kernels-only)

**難度**: ⭐⭐⭐ 進階

## 目標

預測未來一段時間的產品銷量（時間序列回歸）

## 數據集描述

### 特徵說明

| 特徵 | 描述 | 類型 |
|------|------|------|
| date | 日期 | 時間 |
| store | 店舖ID | 類別 |
| item | 商品ID | 類別 |
| sales | 銷量 | 目標變量 |

### 附加特徵

| 特徵 | 描述 |
|------|------|
| 節假日 | 是否為節假日 |
| 促銷 | 是否有促銷活動 |
| 天氣 | 天氣狀況 |
| 價格 | 商品價格 |

## 關鍵洞察

1. **季節性**: 某些商品有明顯季節模式
2. **週期性**: 週末vs工作日銷售差異
3. **節假日效應**: 節假日銷量激增
4. **促銷影響**: 促銷活動顯著提升銷量

## 技術方法

### 時間特徵
- 日/週/月/年週期
- 節假日標記
- 滾動統計量
- 滯後特徵

### 模型
- ARIMA/SARIMA
- Prophet
- LightGBM
- LSTM

### 評估指標
- MAE
- RMSE
- SMAPE

## 使用方法

```bash
python solution.py
```
