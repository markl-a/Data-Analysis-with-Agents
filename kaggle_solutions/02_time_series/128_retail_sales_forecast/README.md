# 128. 零售銷售預測

## 項目概述

這是一個零售銷售時間序列預測項目，利用歷史銷售數據預測未來銷售趨勢，幫助企業進行庫存管理和資源規劃。

**Kaggle 數據集**: [Retail Sales Dataset](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset)

**難度**: ⭐⭐ 中級

## 目標

預測未來一段時間的零售銷售額（時間序列回歸問題）

## 數據集描述

### 特徵說明

| 特徵 | 描述 | 類型 |
|------|------|------|
| date | 日期 | 日期 |
| store | 門店ID | 分類 |
| item | 商品ID | 分類 |
| sales | 銷售量 | 數值（目標） |

### 時間序列特點
- 季節性模式
- 趨勢變化
- 節假日效應
- 促銷影響

## 關鍵洞察

1. **季節性**: 明顯的周、月、年季節性模式
2. **趨勢**: 長期銷售趨勢分析
3. **異常值**: 節假日和促銷期間的銷售異常
4. **門店差異**: 不同門店銷售模式差異

## 技術方法

### 數據預處理
- 時間特徵提取
- 缺失值處理
- 異常值檢測
- 平穩性檢驗

### 特徵工程
- 時間特徵（年、月、週、日）
- 滯後特徵（Lag features）
- 滾動統計特徵
- 節假日標記

### 模型
- ARIMA/SARIMA
- Prophet
- XGBoost
- LightGBM
- LSTM

### 評估指標
- RMSE (均方根誤差)
- MAE (平均絕對誤差)
- MAPE (平均絕對百分比誤差)
- R² 分數

## 使用方法

```bash
python solution.py
```

## 預期結果

- MAPE: < 10%
- R²: > 0.85
