# 110. MNIST 手寫數字識別

## 項目概述

這是深度學習的經典入門項目，通過識別手寫數字圖像來學習圖像分類的基本概念和技術。MNIST 數據集是機器學習領域的 "Hello World"。

**Kaggle 數據集**: [Digit Recognizer](https://www.kaggle.com/competitions/digit-recognizer)

**難度**: ⭐⭐ 中級

## 目標

識別手寫數字 0-9（多類分類問題）

## 數據集描述

### 數據格式

| 屬性 | 描述 |
|------|------|
| 圖像大小 | 28 x 28 像素 |
| 顏色 | 灰度 (0-255) |
| 類別數 | 10 (數字 0-9) |
| 訓練集 | 60,000 張 |
| 測試集 | 10,000 張 |

### 特徵

每張圖像被展平為 784 個特徵 (28 x 28)，每個特徵代表一個像素的灰度值。

## 技術方法

### 數據預處理
- 標準化 (0-1 範圍)
- 數據增強 (旋轉、平移)
- 重塑為原始圖像格式

### 模型

1. **傳統機器學習**
   - Logistic Regression
   - SVM
   - Random Forest
   - KNN

2. **深度學習**
   - MLP (多層感知器)
   - CNN (卷積神經網絡)
   - LeNet-5 架構

### 評估指標
- 準確率
- 混淆矩陣
- 每類別準確率

## 使用方法

```bash
python solution.py
```

## 預期結果

- 傳統 ML: ~95-97%
- 深度學習 (CNN): ~99%+

## 學習要點

- 圖像數據處理
- 卷積神經網絡原理
- 數據增強技術
- 模型評估方法
