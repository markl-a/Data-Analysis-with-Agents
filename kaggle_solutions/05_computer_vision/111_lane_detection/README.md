# 111. 自動駕駛車道檢測

## 項目概述

這是一個計算機視覺項目，通過圖像處理和深度學習技術檢測道路車道線，是自動駕駛和高級駕駛輔助系統 (ADAS) 的核心技術之一。

**Kaggle 數據集**: [TuSimple Lane Detection](https://www.kaggle.com/datasets/manideep1108/tusimple)

**難度**: ⭐⭐⭐ 進階

## 目標

從道路圖像中檢測並標記車道線位置

## 數據集描述

### 輸入

| 類型 | 描述 |
|------|------|
| 圖像 | 道路場景圖像 (1280x720) |
| 標注 | 車道線的像素位置 |

### 挑戰

- 光線變化（白天/夜晚）
- 天氣條件（晴天/雨天）
- 遮擋情況（車輛/陰影）
- 彎道和直道

## 關鍵技術

1. **邊緣檢測**: Canny 算法檢測邊緣
2. **霍夫變換**: 直線檢測
3. **透視變換**: 鳥瞰圖轉換
4. **滑動窗口**: 車道線追蹤
5. **多項式擬合**: 曲線車道檢測

## 技術方法

### 傳統方法
- Canny 邊緣檢測
- 霍夫變換
- 顏色空間轉換 (HSL/LAB)
- 透視變換

### 深度學習方法
- U-Net 語義分割
- LaneNet
- SCNN (Spatial CNN)
- ENet-SAD

### 評估指標
- 準確率
- 誤報率
- 漏報率
- F1 分數

## 使用方法

```bash
python solution.py
```
