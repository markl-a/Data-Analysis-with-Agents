# Internal documentation

These are working documents — milestone summaries, statistics dumps, recommendation backlogs, duplicate quickstarts — kept around for history but not what a new visitor should land on first.

User-facing documentation lives in [`../`](../) (the parent `docs/` directory) and the project [README](../../README.md).

## What's in here

| File | What it is |
|---|---|
| `IMPROVEMENT_RECOMMENDATIONS.md` | Self-audit / improvement backlog |
| `RECOMMENDATION_SOLUTIONS_SUMMARY.md` | One-time summary of the recommendation-system kaggle batch |
| `SOLUTIONS_SUMMARY.md` | One-time aggregated summary of the kaggle solutions tree |
| `STATISTICS.md` | Stats dump — solution counts, line counts, etc. |
| `QUICKSTART_GUIDE.md` | Older variant of the quickstart (the canonical one is the project [README](../../README.md) and `../../QUICKSTART.md`) |
